Listing Studio Privacy Policy

Listing Studio is a private application for its owner's eBay Sandbox testing. It is not a public multi-user service.

Information stored

The application stores product drafts, product photos, seller settings, and encrypted eBay authorization tokens on its server hosted by Render.

Information shared

Selected product facts are sent to OpenAI when the owner requests an AI draft. This version does not send photos to OpenAI.

Creating an offer sends reviewed listing information and signed photo URLs to eBay Sandbox. Anyone possessing a signed photo URL can access that photo. Publishing requires separate explicit approval.

Data management

The owner controls server data, backups, and deletion. Disconnecting the application or deleting its server data does not remove listings already created in eBay Sandbox.
